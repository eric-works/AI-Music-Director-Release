# AI Music Director (IMD)

Timeline-based Music Director for Virtual Singers

AI Music Director (IMD) is designed for AI Covers and virtual singer production. It allows creators to arrange multiple virtual singers on a timeline while maintaining full creative control.

## Features

### 🎤 Virtual Singer Training

- Create and manage virtual singer models
- Import existing AI voice models
- Manage multiple singer profiles

### 🎵 AI Cover Production

- Vocal and instrumental separation
- AI voice conversion
- Fully offline AI cover generation

### 🎬 Timeline Editor

- Timeline-based music arrangement
- Multi-singer performance workflow
- Segment switching and crossfades
- Flexible singer assignment

### ⚙ Runtime Manager

- Downloads AI runtimes when needed
- Keeps installer size small
- Supports offline operation after setup

### 🖥 Customizable User Interface

- Resize and rearrange panels freely
- Dock, float, or hide windows as needed
- Build a workspace that matches your workflow
- Optimize layouts for training, arranging, and mixing tasks

## Design Philosophy

IMD is a **Music Director**, not a **Music Autopilot**.

The software provides tools, analysis and workflow support, while creative decisions remain in the hands of the creator.

You decide:

- Which singer performs
- When singers switch
- How harmonies are arranged
- The artistic direction of the song

# AI Music Director (IMD)

時間軸式虛擬歌手導演系統

AI Music Director (IMD) 專為 AI Cover 與虛擬歌手創作而設計，透過時間軸工作流程編排多位虛擬歌手，讓創作者保有完整的創作主導權。

---

## 主要功能

### 🎤 虛擬歌手訓練

- 建立與管理虛擬歌手模型
- 匯入既有 AI 語音模型
- 管理多位歌手角色

### 🎵 AI Cover 製作

- 人聲與伴奏分離
- AI 歌聲轉換
- 離線生成 AI Cover

### 🎬 Timeline 編輯器

- 時間軸式音樂編排
- 多歌手接唱
- 歌段切換與交叉淡化
- 自由安排演唱者

### ⚙ Runtime Manager

- 按需下載 AI 執行環境
- 降低安裝包體積
- 安裝後可離線運作

### 🖥 可自訂使用者介面

- 自由調整面板位置與大小
- 支援停駐、浮動與隱藏視窗
- 建立符合個人習慣的工作空間
- 針對訓練、編曲與混音流程最佳化配置

---

## 設計理念

IMD 是一位「Music Director（音樂導演）」，

而不是替使用者自動完成創作的 Music Autopilot。

創作者決定：

- 哪位歌手演唱
- 何時切換歌手
- 和聲編排方式
- 歌曲呈現風格

系統負責提供工具與工作流程支援。

---

## 系統需求

- Windows 10 / 11
- 建議使用 NVIDIA GPU
- 首次安裝需連線下載 Runtime
- 安裝完成後可離線使用
